Política de privacidad

Esta página explica de forma clara qué datos personales se tratan a través del sitio web de LAVENDISH y con qué finalidad.

1. Responsable

Los datos identificativos completos del responsable se incorporarán antes de publicar esta versión en producción.

2. Datos tratados en esta web

La versión actual del sitio es informativa y no incluye formularios de contacto, registro de usuarios, reservas, newsletter, cuentas personales ni procesos de compra.

El código de la web no incorpora herramientas propias de analítica, publicidad comportamental, píxeles de seguimiento ni mecanismos destinados a crear perfiles de navegación.

3. Enlaces a terceros

La web contiene enlaces externos, por ejemplo para abrir la ubicación de LAVENDISH en Google Maps. Al seguir un enlace externo, el usuario abandona este sitio y pasa a estar sujeto a las condiciones y políticas de privacidad del servicio de destino.

4. Alojamiento técnico

Este sitio se publica mediante GitHub Pages. La infraestructura de alojamiento puede tratar datos técnicos necesarios para servir, proteger y mantener el sitio. LAVENDISH no utiliza esos datos técnicos para elaborar perfiles comerciales ni para mostrar publicidad personalizada.

5. Si contactas con LAVENDISH por otros medios

Si una persona facilita voluntariamente datos personales a LAVENDISH por un canal distinto de esta web, dichos datos deberán utilizarse únicamente para atender la consulta, solicitud o relación correspondiente y conservarse durante el tiempo necesario para esa finalidad y para cumplir las obligaciones legales aplicables.

6. Derechos

Cuando exista un tratamiento de datos personales, la persona interesada podrá ejercer los derechos que le reconozca la normativa aplicable, incluidos los derechos de acceso, rectificación, supresión, oposición, limitación y, cuando proceda, portabilidad.

El canal específico para ejercer estos derechos se añadirá junto con los datos completos del responsable antes de publicar esta versión.

7. Cambios en esta política

Esta política deberá revisarse si la web incorpora nuevas funciones que impliquen tratamiento de datos, como formularios, reservas online, analítica, publicidad, newsletter o integraciones de terceros.
