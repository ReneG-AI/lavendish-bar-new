2. Alcance de esta política

Esta política se refiere al tratamiento de datos personales relacionado con esta web y con las comunicaciones que se inicien a través del correo de contacto legal indicado en ella.

La actividad ordinaria del establecimiento puede implicar otros tratamientos ajenos a la web —por ejemplo, relaciones con proveedores, personal o clientes— que, cuando corresponda, deberán contar con su información específica.

3. Qué datos se tratan

Navegación por la web

El código propio de LAVENDISH no incorpora formularios, registro de usuarios, newsletter, herramientas propias de analítica, publicidad comportamental, píxeles de seguimiento ni sistemas destinados a crear perfiles de navegación.

La web se aloja mediante GitHub Pages. GitHub informa de que, al visitar un sitio de GitHub Pages, la dirección IP del visitante se registra y almacena con fines de seguridad. LAVENDISH no utiliza esos registros para realizar analítica comercial ni elaborar perfiles.

Comunicaciones por correo

Si escribes voluntariamente a LAVENDISH, podrán tratarse los datos que facilites en el mensaje, como nombre, dirección de correo, contenido de la consulta y cualquier información adicional que decidas incluir.

Recomendación: no envíes por correo datos especialmente sensibles que no sean necesarios para gestionar tu consulta.

5. Destinatarios y proveedores tecnológicos

No se venden datos personales ni se ceden con fines publicitarios. Los datos podrán ser tratados por proveedores tecnológicos cuando sea necesario para prestar el servicio, como el alojamiento web o el correo electrónico, y por autoridades públicas cuando exista una obligación legal.

La web se publica mediante GitHub Pages / GitHub. El correo indicado utiliza infraestructura de un proveedor de correo electrónico. Cada proveedor puede tratar datos técnicos conforme a sus condiciones, políticas y mecanismos legales aplicables.

6. Transferencias internacionales

Algunos proveedores tecnológicos globales pueden prestar servicios o contar con infraestructura fuera del Espacio Económico Europeo. Cuando resulte aplicable, esos tratamientos deberán apoyarse en una decisión de adecuación, cláusulas contractuales tipo u otra garantía reconocida por la normativa de protección de datos.

Para el tratamiento realizado directamente por GitHub como plataforma, puede consultarse su declaración de privacidad enlazada en el apartado anterior.

7. Plazos de conservación

  • Consultas por correo: durante el tiempo necesario para responder y gestionar la relación derivada de la consulta; después podrán conservarse bloqueadas cuando sea necesario para atender posibles responsabilidades legales.
  • Solicitudes de derechos: durante el plazo necesario para acreditar su correcta atención y cumplir las obligaciones legales correspondientes.
  • Datos técnicos de GitHub Pages: conforme a los plazos y criterios establecidos por GitHub para su infraestructura y seguridad.

8. Tus derechos

Puedes solicitar, cuando resulte aplicable, el acceso a tus datos personales, su rectificación o supresión, la limitación del tratamiento, oponerte al tratamiento y solicitar la portabilidad.

Para ejercerlos, escribe a jiayi19733@gmail.com indicando qué derecho deseas ejercer y la información necesaria para localizar la relación o comunicación correspondiente. Si existen dudas razonables sobre la identidad de quien realiza la solicitud, podrá pedirse información adicional estrictamente necesaria para verificarla.

Si consideras que el tratamiento de tus datos no se ajusta a la normativa, puedes presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD).

9. Decisiones automatizadas y perfiles

La web actual no adopta decisiones automatizadas con efectos jurídicos o significativos sobre los usuarios ni realiza elaboración de perfiles con fines comerciales.

10. Menores

La web no dispone de mecanismos destinados a recoger datos personales de menores. Si se detectara que se han recibido datos de un menor sin una base válida para tratarlos, se adoptarán las medidas razonables para eliminarlos cuando corresponda.

11. Seguridad

Se aplican medidas razonables y proporcionadas a la naturaleza del sitio para reducir riesgos de acceso no autorizado, pérdida, alteración o divulgación de información. Ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

12. Cambios en esta política

Esta política se revisará cuando cambien las funcionalidades de la web, los proveedores, la forma de contacto o los tratamientos de datos. Si en el futuro se incorporan formularios, reservas, analítica, publicidad, newsletter o cuentas de usuario, la información se actualizará antes de su puesta en producción.

Normativa de referencia: Reglamento (UE) 2016/679 (RGPD) y Ley Orgánica 3/2018, de Protección de Datos Personales y garantía de los derechos digitales.
