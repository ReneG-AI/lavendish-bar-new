## Important production rule

These are Phase 3A reference plates, not the final production asset decision.

Before merging any cinematic intro into `main`:

1. decide whether these reference plates meet the final LAVENDISH art direction;
2. if retained, download and optimise local copies rather than depending on a third-party runtime URL;
3. if replaced, create dedicated LAVENDISH-specific plates with equivalent composition;
4. run full desktop/mobile/Safari QA after the final local assets are in place;
5. preserve source/licensing documentation for any retained third-party photography.
